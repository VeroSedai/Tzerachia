# Tech Stack Guidelines
- **Framework:** React Native with Expo (TypeScript)
- **Navigation:** React Navigation (Bottom Tab Navigator)
- **State:** React Context API + AsyncStorage for persistence
- **Palette:** Soft Sage Green (`#7A9A8B`), Sky Blue (`#A8C3C8`), Off-white (`#F9F9F6`), Dark Charcoal (`#2C3E35`).
