# Simply Clean App - Specifiche Funzionali

## 1. Visione del Prodotto
Un'applicazione mobile basata sul metodo "Simply Clean" di Becky Rapinchuk per gestire le pulizie di casa in 10-15 minuti al giorno.

## 2. Navigazione (Bottom Tab)
1. **Oggi ("Today"):** 5 Daily Tasks (reset automatico a mezzanotte), Weekly Task del giorno, Widget Timer integrato (10/15 min) e scorciatoia alla Guida del giorno.
2. **Pianificazione ("Schedule"):** Calendario settimanale con task preimpostate (Lunedì: Bagni, Martedì: Spolverare, Mercoledì: Aspirapolvere, Giovedì: Pavimenti, Venerdì: Catch-all, Sabato: Lenzuola/Asciugamani, Domenica: Daily Tasks).
3. **Catch-All (Venerdì):** Le task settimanali saltate durante la settimana vengono spostate qui automaticamente senza penalizzazioni.
4. **Sfide ("Challenges"):** Programmi opzionali "7-Day Kick Start" e "28-Day Challenge" con progresso visivo.
5. **Guide & Ricette ("Guides"):** Categorie, barra di ricerca, ricette fai-da-te e modalità "Esecuzione Guidata con Step".
